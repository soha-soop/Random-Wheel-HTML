Firebase 설정이 필요해요

이 도구는 실시간 동기화를 위해 무료 Firebase Realtime Database를 사용합니다. 파일 상단의 FIREBASE_CONFIG 값을 본인의 Firebase 프로젝트 정보로 채워주세요.

  1. Firebase 콘솔에서 새 프로젝트 생성
  2. 왼쪽 메뉴 빌드 → Realtime Database 에서 데이터베이스 생성 (테스트 모드)
  3. 프로젝트 설정 → 일반 → 내 앱 → 웹 앱 추가 후 firebaseConfig 복사
  4. 이 HTML 파일 상단의 FIREBASE_CONFIG 부분에 붙여넣기
